# Декомпозиция задачи

## Требования (ТЗ)

Сделать приложение, которое умеет в:

* Список приложений
* Карточку приложений
* Установку, удаление приложений

## Эпики

### Настройка связи с тестовым бд (4-5 дней) <EPIC>
(*Вынесли в отдельный эпик, т.к. требуется взаимодействие с другим отделом*)
Поднять тестовую базу данных, которая симулирует настоящую с ограниченным количеством приложений. База данных должна содержать: список приложений (см. соответствующий эпик), по каждому приложению в этом списке подробную информацию (см. эпик по карточке приложения), и установочные файлы .apk

**Задачи:**
* Взять примерный список приложений, сгенерировав их корпоративной нейросетью (8 часов) <**Backlog**>
* Подробные данные составить в соответствии с макетом - см. эпик Карточка приложения (8 часов) <**Backlog**>
* Расположить их в сетевом бд, к которому можно иметь доступ из локальной корпоративной сети (8 часов) <**Backlog**>
* Написать документацию по API и доступу (4 часа) <**Backlog**>

### Реализация списка приложений (1.5 недели) <EPIC>
Создать рабочий интерфейс списка приложений.  Результат должен соответствовать макету - [макет](https://cloud.mail.ru/public/rUXp/Fmwx9zssg)

**Задачи:**
* Набросать макет в Composable (8 часов) <**Backlog**>
* Интегрировать с карточкой приложения, использовать мок-данные. Интеграция предполагает навигацию по клику на любой элемент списка на карточку приложения (см. соответствующий эпик). Карточку приложения захардкодить (4 часа) <**Backlog**>
* Протестировать UI с помощью мок-данных (2-3 часа) <**Backlog**>
* Создать database через Room (4 часа) <**Backlog**>
* Связать Room-database с локальным тестовым бд через Retrofit (4 часа) <**Backlog**>
* Настроить навигацию на карточку приложения по ID (8 часов) <**Backlog**>


### Карточка приложений (1.5 недели) <EPIC>
Создать пользовательский интерфейс карточки приложений. Внешний вид должен соответствовать макету - [макет](https://www.rustore.ru/help/assets/images/download-f690244ac26c7242a94e303d8a03796e.webp)

**Задачи:**
* Набросать макет UI в Composable (4 часа)
* Реализовать выпадение подробной информации приложения по клику (2 часа) <**Backlog**>
* Сделать заглушку на пункте с отзывами, по нажатию - пустота (TODO: будущий эпик, 2 часа) <**Hold**>
* Реализовать локальный бд через Room (4 часа) <**Backlog**>
* Подвязать локальный бд с тестовым через Retrofit (4 часа) <**Backlog**>
* Связать экран карточки приложения с экраном списка через навигацию (4 часа) - (см. соответствующий эпик) <**Backlog**>
* Протестировать отображение контента с тестового сетевого бд (2 часа) <**Backlog**>

### Установка/удаление приложений (1.5 недели) <EPIC>
На экране карточки приложений (см. соответствующий эпик) должна присутствовать кнопка "Установка/удаление". При нажатии на нее соответствующее приложение должно быть установлено/удалено на/с устройства. После установки необходимо реализовать возможность удаления или открытия приложения

**Задачи:** 
* Протестировать установку/открытие/удаление приложения через статус в viewmodel, сделав кнопку кликабельной. При установленном приложении удаление реализуется через дополнительную кнопку рядом с кнопкой "Открыть" (4 часа) <**Backlog**>
* Взять тестовый .apk файл, подвязять к UI и протестировать (через Intents) удаление/установку приложения по клику (4 часа) <**Backlog**>
* Добавить возможность войти в приложение, если оно уже установлено, через кнопку "Открыть" (4 часа) <**Backlog**>
* Реализовать локальный бд через Room - добавить поле с .apk (2 часа) <**Backlog**>
* Подвязать локальный бд с тестовым через Retrofit - добавить поле с .apk (2 часа) <**Backlog**>
* Связаться с бд с тестовыми .apk через Room-Retrofit (4 часа) <**Backlog**>
* Реализовать установку/удаление нескольких приложений одновременно (4 часа) <**Backlog**>
